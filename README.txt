ICT251 Activity 6 - IT Support Desk

1. Extract the ZIP file.
2. Open the activity6-frontend folder in Visual Studio Code.
3. Replace the student-number placeholder in index.html.
4. Run index.html using VS Code Live Server (recommended).
5. Test adding, viewing, editing, deleting, searching, filtering and refreshing.
6. For hosting, upload the complete activity6-frontend folder to Netlify using manual deploy.

Important:
- This project uses localStorage in the browser.
- Data is local to the browser and website origin; it is not shared between devices.
- Do not change the required record field names: id, title, category, description, status.
- Keep this Activity 6 hosted URL separate from the integrated Activity 8 URL.
